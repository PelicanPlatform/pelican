## pelican-server lot reclaim

Reclaim a lot and its descendants

### Synopsis

Mark a storage lot (and its descendants) as reclaimed. Reclamation severs the
lot's accounting tie to its paths so its usage no longer counts toward quotas;
it is recorded in an append-only ledger. Requires an administrative token for
the cache.

```
pelican-server lot reclaim <lotName> [flags]
```
