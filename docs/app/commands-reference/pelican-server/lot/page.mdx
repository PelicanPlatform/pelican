## pelican-server lot

Manage storage lots (reservations) on a Pelican cache

### Synopsis

Provide commands to list, inspect, create, update, delete, and reclaim storage
lots (reservations) on a Pelican cache. These commands interact with the
cache's lot management API and require an administrative token for the cache.

### Options

```
  -h, --help            help for lot
  -s, --server string   Web URL of the Pelican cache (e.g. https://my-cache.com:8447)
  -t, --token string    Path to an admin token file
```
