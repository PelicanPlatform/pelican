## pelican-server lot list

List the lots known to a cache

### Synopsis

List the names of the storage lots configured on a Pelican cache. Requires an administrative token for the cache.

```
pelican-server lot list [flags]
```

### Options

```
  -h, --help           help for list
      --owner string   Only list lots owned by this issuer URL
      --recursive      Include child lots (default true)
```
