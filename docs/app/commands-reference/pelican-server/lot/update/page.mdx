## pelican-server lot update

Update a lot's management-policy attributes

### Synopsis

Update the management-policy attributes of an existing storage lot.

Only the attributes you specify are sent; quota flags are in GB and time flags
are UTC 'YYYY-MM-DD HH:MM:SS'. Requires an administrative token for the cache.

```
pelican-server lot update <lotName> [flags]
```
