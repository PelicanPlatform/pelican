## pelican-server lot delete

Delete a lot and its descendants

### Synopsis

Delete a storage lot from a Pelican cache. Deletion is recursive: the named
lot and all of its descendant lots are removed. Requires an administrative
token for the cache.

```
pelican-server lot delete <lotName> [flags]
```
