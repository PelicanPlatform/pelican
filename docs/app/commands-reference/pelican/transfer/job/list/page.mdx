## pelican transfer job list

List the transfer jobs owned by the caller

### Synopsis

List the transfer jobs on the transfer server that belong to the
authenticated caller, most recently created first.  The server never returns
another user's jobs.

```
pelican transfer job list [flags]
```

### Options

```
  -h, --help            help for list
      --limit int       Maximum number of jobs to return (the server caps this at 100) (default 10)
      --offset int      Number of jobs to skip, for paging through a long list
      --status string   Only show jobs in this state (pending, running, completed, failed, cancelled)
```
